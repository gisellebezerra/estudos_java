# 🧑‍💻 Algoritmos e Estruturas de Dados - Estudos em Java

Este repositório contém os projetos e exercícios que desenvolvi enquanto estudava **Algoritmos**, **Estruturas de Dados** e **Fundamentos da Linguagem Java**. O objetivo principal é praticar e aplicar conceitos de **Programação Orientada a Objetos (POO)**, estruturas de controle, e aprender como essas bases formam o alicerce de soluções mais complexas.

## 📚 Conteúdo

Os projetos e códigos contidos neste repositório cobrem os seguintes tópicos:

- **Fundamentos da Linguagem Java**:
  - Tipos de dados, operadores, entrada/saída
  - Manipulação de Strings e Arrays
  - Estruturas de controle (`if`, `switch`, `while`, `for`)

- **Estruturas de Controle**:
  - Condições e loops
  - Como controlar o fluxo de execução do código

- **Classes, Objetos, Métodos**:
  - Definição de classes e objetos
  - Criando e utilizando métodos
  - Encapsulamento de dados e uso de modificadores de acesso

- **Programação Orientada a Objetos (POO)**:
  - Conceitos de **herança**, **polimorfismo**, **abstração** e **encapsulamento**
  - Como organizar e modularizar o código com objetos e classes
  - Prática com exemplos e exercícios de POO
